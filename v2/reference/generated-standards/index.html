    MailAddress()

    Represent one mailbox from an RFC 5322 or RFC 6532 address field.

    Attributes:

    Name Type Description
    DisplayName

    Decoded human-readable phrase preceding the address.
    Email

    Complete address specification.
    LocalPart

    Portion of the address before @.
    Domain

    Portion of the address after @.
    RawValue

    Original mailbox value when available.
    IsInternationalized

    Whether the source contains non-ASCII characters.

    Initialize an empty mailbox.

    DisplayName instance-attribute ¶

    DisplayName = ''

    The human-readable name associated with the email address (optional).

    Email instance-attribute ¶

    Email = ''

    The actual email address (user@domain.com format).

    Bases: str, Enum

    Control how parser diagnostics affect the result.

    MODERN and LENIENT return recoverable messages with diagnostics. STRICT raises when any error-level diagnostic is collected.
