    Generated MIME API¶

    ContentType¶

    EMLMailReader.Content_Type.ContentType ¶

    ContentType()

    Represent the effective and source MIME content type for one entity.

    The class preserves whether Content-Type was explicit, retains all decoded parameters, and exposes frequently used MIME values as dedicated attributes.

    Attributes:

    Name Type Description
    MediaType

    Effective lowercase type/subtype value.
    Charset

    Declared text charset, defaulting to MIME US-ASCII.
    Boundary

    Multipart boundary or an empty string.
    Name

    Suggested content name from the name parameter.
    Parameters dict[str, str]

    All decoded parameters keyed by lowercase name.
    RawValue

    Original Content-Type field value, excluding the field name.
    IsExplicit

    Whether the source contained a Content-Type field.

    Initialize the RFC 2045 default text/plain; charset=us-ascii.

    MediaType instance-attribute ¶

    MediaType = 'text/plain'

    The main media type and subtype (e.g., 'text/plain', 'image/jpeg').

    Charset instance-attribute ¶

    Charset = 'us-ascii'

    Character encoding used for text content (defaults to US-ASCII per RFC 2045).

    Boundary instance-attribute ¶

    Boundary = ''

    Delimiter string used to separate parts in multipart MIME entities.

    Name instance-attribute ¶

    Name = ''

    Suggested name for the content, often used for attachments.

    Parameters instance-attribute ¶

    Parameters: dict[str, str] = {}

    All decoded MIME parameters, including RFC 2231 extensions.

    ContentDisposition¶

    EMLMailReader.Content_Disposition.ContentDisposition ¶

    ContentDisposition()

    Represent a parsed MIME Content-Disposition field.

    The model retains the original field value and every decoded parameter while exposing common RFC 2183 metadata such as the filename, size, and lifecycle dates through dedicated attributes.

    Attributes:

    Name Type Description
    DispositionType

    Lowercase registered or extension disposition token.
    FileName

    Suggested filename decoded from the filename parameter.
    CreationDate ParsedDateTime | None

    Parsed creation-date value, if present.
    ModificationDate ParsedDateTime | None

    Parsed modification-date value, if present.
    ReadDate ParsedDateTime | None

    Parsed read-date value, if present.
    Size

    Declared content size in bytes, or zero when absent or invalid.
    Parameters dict[str, str]

    All decoded parameters keyed by lowercase name.
    RawValue

    Original Content-Disposition field value.
    IsExplicit

    Whether the source contained a Content-Disposition field.

    Initialize an empty, non-explicit disposition value.

    DispositionType instance-attribute ¶

    DispositionType = ''

    The registered or extension disposition token.

    FileName instance-attribute ¶

    FileName = ''

    The suggested filename for the MIME entity when saved to disk.

    CreationDate instance-attribute ¶

    CreationDate: ParsedDateTime | None = None

    RFC 2822 formatted date when the MIME entity was originally created.

    ModificationDate instance-attribute ¶

    ModificationDate: ParsedDateTime | None = None

    RFC 2822 formatted date when the MIME entity was last modified.

    Size instance-attribute ¶

    Size = 0

    Size of the MIME entity content in bytes.
