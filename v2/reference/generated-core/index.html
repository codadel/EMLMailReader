    MailReader¶

    EMLMailReader.Mail_Reader.MailReader ¶

    MailReader(logging_mode: LoggingMode = LoggingMode.NONE, TargetLoggingFolder: str = '', parsing_mode: ParsingMode | str = ParsingMode.MODERN, limits: ParserLimits | None = None)

    Configure and execute standards-aware EML parsing.

    A reader owns one parser configuration, including its receiver/strict mode, resource limits, and optional diagnostic logging destination.

    Attributes:

    Name Type Description
    ParsingMode

    Mode value supplied when the reader was created.
    LoggingMode

    Configured diagnostic logging destination.

    Initialize a reusable parser facade.

    Parameters:

    Name Type Description Default
    logging_mode LoggingMode

    Destination for parser diagnostic log messages.

    		 NONE
    TargetLoggingFolder str

    Existing directory used by file logging.

    		 ''
    parsing_mode ParsingMode | str

    Receiver behavior or strict conformance enforcement.

    		 MODERN
    limits ParserLimits | None

    Resource guards; defaults to :class:ParserLimits.

    		 None

    Raises:

    Type Description
    FolderNotAvailableError

    If file logging is requested with an unavailable target directory.

    RxMailMessage¶

    EMLMailReader.Rx_Mail_Message.RxMailMessage ¶

    RxMailMessage()

    Represent one parsed Internet message or MIME entity.

    The same class is used for the root message and every node in its recursive MIME tree. Internet-message fields, MIME metadata, source bytes, decoded bodies, child entities, and parser diagnostics therefore remain available through one canonical model.

    Attributes:

    Name Type Description
    Headers

    Ordered, duplicate-preserving header collection.
    From

    Structured originator address list.
    Sender

    Structured sender address list.
    ReplyTo

    Structured Reply-To address list.
    To

    Structured primary-recipient address list.
    Cc

    Structured carbon-copy address list.
    Bcc

    Structured blind-copy address list.
    Subject

    Decoded Subject field value.
    Date ParsedDateTime | None

    Structured parsed Date value or None.
    MessageID ParsedMessageID | None

    Structured Message-ID value or None.
    InReplyTo list[ParsedMessageID]

    Parsed identifiers from the In-Reply-To field.
    References list[ParsedMessageID]

    Parsed identifiers from the References field.
    Comments list[str]

    Decoded Comments field values in source order.
    Keywords list[str]

    Decoded Keywords field values in source order.
    Received list[str]

    Unfolded Received values in source order.
    ReturnPath

    Unfolded Return-Path value.
    ResentBlocks list[ResentBlock]

    Contiguous structured Resent field groups.
    TraceBlocks list[TraceBlock]

    Structured Return-Path and Received groups.
    ContentType

    Effective and source MIME content type.
    ContentDisposition ContentDisposition | None

    Parsed disposition or None.
    ContentTransferEncoding

    Lossless transfer-encoding value.
    MimeVersion

    Unfolded MIME-Version field value.
    ContentDescription

    Decoded Content-Description value.
    ContentID ParsedMessageID | None

    Structured Content-ID value or None.
    MessagePartial MessagePartialInfo | None

    message/partial metadata or None.
    ExternalBodyAccess ExternalBodyAccessInfo | None

    message/external-body metadata or None.
    RawSource

    Source bytes for this entity; exact input bytes at the root.
    RawBody

    Body bytes before content-transfer decoding.
    DecodedBody

    Transfer-decoded leaf payload bytes.
    Children list[RxMailMessage]

    Direct child MIME entities.
    Preamble

    Text preceding the first multipart boundary.
    Epilogue

    Text following the closing multipart boundary.
    Diagnostics list[ParseDiagnostic]

    Standards findings attached to this entity.

    Initialize an empty message using RFC/MIME default field values.

    IsMultiPart property ¶

    IsMultiPart: bool

    Return whether the entity is a multipart container or has children.

    Body property ¶

    Body: str

    Return the preferred decoded text for this MIME subtree.

    Leaves return their decoded text. multipart/alternative chooses its last non-empty alternative; other containers choose the first non-empty child body.

    TextBody property ¶

    TextBody: str

    Return the first decoded text/plain body in this subtree.

    HtmlBody property ¶

    HtmlBody: str

    Return the first decoded text/html body in this subtree.

    Name property ¶

    Name: str

    Return the disposition filename or fallback Content-Type name.

    IsInline property ¶

    IsInline: bool

    Return whether the entity has an explicit inline disposition.

    IsAttachment property ¶

    IsAttachment: bool

    Return whether the entity should be exposed as an attachment.

    Explicit attachment dispositions qualify. A named entity also qualifies unless it is explicitly inline.

    Attachments property ¶

    Attachments: tuple[RxMailMessage, ...]

    Return attachment entities in this subtree as an immutable tuple.

    InlineResources property ¶

    InlineResources: tuple[RxMailMessage, ...]

    Return explicitly inline entities in this subtree as an immutable tuple.

    export_as_json ¶

    export_as_json() -> str

    Serialize the canonical recursive schema as Unicode-preserving JSON.

    to_dict ¶

    to_dict() -> JsonObject

    Return the complete JSON-compatible canonical message schema.

    Source and decoded byte payloads are intentionally omitted. Attachment and inline-resource views are not duplicated because those entities already appear recursively under children.

    save_attachments ¶

    save_attachments(TargetFolderPath: str) -> None

    Write every attachment payload in this subtree to a directory.

    Filenames are reduced to their basename; empty or unsafe basename-only values use attachment. Existing files with the same name are overwritten.

    Parameters:

    Name Type Description Default
    TargetFolderPath str

    Existing destination directory.

    		 required

    Raises:

    Type Description
    FolderNotAvailableError

    If the destination directory is missing.
