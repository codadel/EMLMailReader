    Attachments¶

    MailAttachment¶

    EMLMailReader.Mail_Attachment.MailAttachment ¶

    MailAttachment()

    Represents a file attachment found in an email message.

    This class encapsulates all information about an email attachment including its content, metadata, and MIME properties required for proper handling and extraction.

    Name instance-attribute ¶

    Name = str()

    The filename of the attachment as it should appear when saved.

    ContentType instance-attribute ¶

    ContentType = ContentType()

    MIME Content-Type information including media type and parameters.

    ContentDisposition instance-attribute ¶

    ContentDisposition = ContentDisposition()

    Content-Disposition header information including disposition type and metadata.

    Contents instance-attribute ¶

    Contents = bytes()

    The actual binary content of the attachment file.

    ContentID instance-attribute ¶

    ContentID = str()

    Unique identifier for the attachment, used for referencing in HTML content.

    parse_values ¶

    parse_values(contents: bytes, content_type: ContentType, content_disposition: ContentDisposition, content_id: str)

    Initializes the MailAttachment object with provided content and metadata.

    This method populates all attachment properties and determines the appropriate filename from either the Content-Type name parameter or Content-Disposition filename.

    Parameters:

    Name Type Description Default
    contents bytes

    Binary content of the attachment file.

    		 required
    content_type ContentType

    Parsed Content-Type header information.

    		 required
    content_disposition ContentDisposition

    Parsed Content-Disposition header information.

    		 required
    content_id str

    Content-ID value for referencing the attachment.

    		 required

    Returns:

    Type Description

    None - modifies the object's properties in place.

    MailAttachmentCollection¶

    EMLMailReader.Mail_Attachment.MailAttachmentCollection ¶

    MailAttachmentCollection()

    A collection class to manage multiple MailAttachment instances.

    This class provides a container for storing and manipulating lists of email attachments found within an email message, facilitating batch operations and iteration.

    append ¶

    append(attachment: MailAttachment)

    Adds a MailAttachment instance to the end of the collection.

    Parameters:

    Name Type Description Default
    attachment MailAttachment

    MailAttachment object to be added to the collection.

    		 required

    Returns:

    Type Description

    None - modifies the collection in place.

    length ¶

    length() -> int

    Returns the number of MailAttachment items in the collection.

    Returns:

    Type Description
    int

    Integer count of MailAttachment instances in the collection.

    export_as_list ¶

    export_as_list() -> list

    Exports the collection as a new list of MailAttachment instances.

    This method creates a deep copy of the internal collection to prevent external modification of the collection's internal state.

    Returns:

    Type Description
    list

    A new list containing deep copies of all MailAttachment instances.
