    Utilities and exceptions¶

    LoggingMode¶

    EMLMailReader.Enumerations.LoggingMode ¶

    Bases: Enum

    Enumeration defining different output destinations for logging messages.

    This controls where log messages are written during EML file processing.

    CONSOLE class-attribute instance-attribute ¶

    CONSOLE = 1

    Log messages are printed to the console/terminal.

    FILE class-attribute instance-attribute ¶

    FILE = 2

    Log messages are written to a log file.

    NONE class-attribute instance-attribute ¶

    NONE = 3

    Logging is disabled (no output generated).

    Logger¶

    EMLMailReader.Processing_Logs.Logger ¶

    A static utility class for managing logging configuration and output during EML processing.

    This class provides centralized logging functionality with support for console output, file output, or disabled logging. It integrates with Python's standard logging module to provide consistent log formatting and multiple output destinations.

    TextEncoding¶

    EMLMailReader.Text_Encoding.TextEncoding ¶

    Static utility class for decoding various text encodings used in MIME content.

    This class provides methods to decode Base64 and Quoted-Printable encoded content commonly found in email messages. It handles both text content and binary file attachments, with proper character set handling for internationalization.

    decode_quoted_printable_string staticmethod ¶

    decode_quoted_printable_string(
    encoded_string: str,
    string_charset: str,
    is_header: bool,
) -> str

    [INTERNAL USE ONLY] Decodes Quoted-Printable encoded text content to readable string.

    Quoted-Printable encoding is used for text that contains mostly ASCII characters with occasional non-ASCII characters. This method handles the decoding and character set conversion to produce properly formatted Unicode text.

    Parameters:

    Name Type Description Default
    encoded_string str

    Quoted-Printable encoded string to decode.

    		 required
    string_charset str

    Character encoding of the original text (e.g., 'utf-8', 'iso-8859-1').

    		 required
    is_header bool

    Whether the content is from an email header (affects decoding rules).

    		 required

    Returns:

    Type Description
    str

    Decoded Unicode string with proper character encoding.

    [INTERNAL USE ONLY] Decodes Base64 encoded text content to readable string.

    Name Type Description Default

    decode_base64_file(file_contents: str) -> bytes

    Decodes Base64 encoded binary file content back to original bytes.

    This method is used to extract file attachments from email messages. Base64 encoding allows binary files to be transmitted safely through text-based email systems.

    decode_header staticmethod ¶

    decode_header(encoded_string: str) -> str

    Decodes RFC 2047 encoded email headers to readable Unicode text.

    Email headers may contain encoded content in the format =?charset?encoding?data?= where encoding is either 'Q' (Quoted-Printable) or 'B' (Base64). This method detects and decodes such headers, returning plain Unicode text.

    Parameters:

    Name Type Description Default
    encoded_string str

    Potentially encoded header string to decode.

    		 required

    Returns:

    Type Description
    str

    Decoded Unicode string, or original string if no encoding detected.

    Raises:

    Type Description
    InvalidEncodingError

    If an unsupported encoding method is encountered.

    InvalidEncodingError¶

    EMLMailReader.Custom_Exceptions.InvalidEncodingError ¶

    InvalidEncodingError(EncodedValue: str = str())

    Bases: Exception

    A custom exception class to report invalid or unsupported text encoding errors.

    This exception is raised when the library encounters an encoding type that is not supported or when decoding fails due to invalid encoded content.

    EncodedValue instance-attribute ¶

    EncodedValue = EncodedValue

    The invalid encoded string that caused the error.

    Message instance-attribute ¶

    Message = 'Invalid encoding used'

    Descriptive error message.

    FileMissingError¶

    EMLMailReader.Custom_Exceptions.FileMissingError ¶

    FileMissingError(filePath: str)

    Bases: Exception

    A custom exception class to report when a required file is missing or inaccessible.

    This exception is raised when attempting to read an EML file that doesn't exist at the specified path or when file access permissions are insufficient.

    filePath instance-attribute ¶

    filePath = filePath

    The file path that was not found or is inaccessible.

    IncompleteHeaderError¶

    EMLMailReader.Custom_Exceptions.IncompleteHeaderError ¶

    IncompleteHeaderError(HeaderValue: str, LineInFile: int)

    Bases: Exception

    A custom exception to report malformed or incomplete email headers in EML files.

    This exception is raised when a header line is found that doesn't conform to the expected format (missing colon separator, continuation without initial header, etc.).

    InvalidHeaderValue instance-attribute ¶

    InvalidHeaderValue = HeaderValue

    The malformed header content that caused the error.

    LineInFile instance-attribute ¶

    LineInFile = LineInFile

    The line number in the EML file where the error occurred.

    EMLMailReader.Custom_Exceptions.FolderNotAvailableError ¶

    FolderNotAvailableError(folderPath: str)

    Bases: Exception

    A custom exception class to report when a required directory is missing or inaccessible.

    folderPath instance-attribute ¶

    folderPath = folderPath

    The folder path that was not found or is inaccessible.
